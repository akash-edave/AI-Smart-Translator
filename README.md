### Your Personal Language Assistant

AI Smart Translator is an Android application developed using Kotlin and Jetpack Compose. It helps users translate text between multiple languages with additional features like voice input, image text recognition (OCR), text-to-speech, and translation history.

The application uses Google ML Kit to provide an easy and convenient translation experience.

---

## ✨ Features

- 🌍 **Multi-Language Translation** – Translate text between 15 different languages.
- 🎤 **Voice Input** – Convert speech into text using speech recognition.
- 🖼️ **Image Text Recognition (OCR)** – Extract text from images using Google ML Kit.
- 🔊 **Text-to-Speech** – Listen to translated text.
- 📋 **Copy Translation** – Copy translated text with one click.
- 🔄 **Swap Languages** – Quickly switch source and target languages.
- 🕘 **Translation History** – View and reuse previous translations during the current session.
- 🌙 **Modern Dark UI** – Clean and user-friendly dark-themed interface.
- 📱 **Responsive Design** – Built using Jetpack Compose.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**Step 1: Clone the Repository**

```bash
git clone https://github.com/akash-edave/AI-Smart-Translator.git
```

**Step 2: Open in Android Studio**

Open Android Studio and select the cloned project folder.

**Step 3: Sync Gradle**

Wait for Gradle synchronization and dependency installation to complete.

**Step 4: Run the Application**

Connect an Android device or start an emulator.

Click the Run ▶ button in Android Studio.

## 🔍 How It Works

1. Select the source and target languages.
2. Enter text manually, use voice input, or select an image from the gallery.
3. The application processes the input.
4. Google ML Kit translates the text into the selected language.
5. View, copy, or listen to the translated result.

**Offline Support:** ML Kit language models can be downloaded for supported languages, allowing translation without an internet connection after the required model has been downloaded.
